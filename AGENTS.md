# Campaign Workflow

This repository contains shared Markdown skills and templates for engineering and
research campaigns across agent harnesses.

- Maintain the shared skills in `skills/`; both plugin manifests use that directory.
- For workflow changes, consult [the overview](skills/campaign-start/references/campaign-workflow-overview.md).
- Keep this file small. Detailed procedures belong in the skills and overview.
- Check installer changes with `python3 -m unittest discover -s tests -v`.

Campaign records are user data; preserve existing content when adapting the workflow.
