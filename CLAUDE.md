# Campaign Workflow

This repository maintains the shared skills in `skills/` for Claude Code, Codex,
and other harnesses. Both plugin manifests use those same files.

For workflow changes, consult
[the overview](skills/campaign-start/references/campaign-workflow-overview.md).
Keep detailed procedures there and in the skills. Check installer changes with
`python3 -m unittest discover -s tests -v`.

Campaign records are user data; preserve existing content when adapting the workflow.
